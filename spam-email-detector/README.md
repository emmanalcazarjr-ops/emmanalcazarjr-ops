# Spam Email Detector

A machine learning project that classifies emails as spam or not spam using a Naive Bayes classifier.

## Description

This project demonstrates text classification using:
- TF-IDF vectorization for text feature extraction
- Multinomial Naive Bayes classifier
- Sample email dataset with spam/ham labels

## Installation

```bash
pip install -r requirements.txt
```

## Usage

```bash
python main.py
```

## Expected Output

The script will:
1. Display dataset statistics
2. Train the spam detection model
3. Show accuracy metrics and classification report
4. Classify new sample emails

## Tech Stack

- Python
- scikit-learn
- pandas
- numpy
