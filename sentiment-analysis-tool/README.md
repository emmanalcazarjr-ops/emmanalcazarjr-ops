# Sentiment Analysis Tool

A natural language processing project that analyzes text sentiment (positive, negative, or neutral) using TextBlob.

## Description

This project demonstrates sentiment analysis using:
- TextBlob for natural language processing
- Polarity scoring (-1 to 1)
- Sentiment classification (positive, negative, neutral)

## Installation

```bash
pip install -r requirements.txt
```

## Usage

```bash
python main.py
```

## Expected Output

The script will:
1. Analyze sample product reviews
2. Display sentiment labels and polarity scores
3. Show summary statistics
4. Demonstrate with custom text examples

## Tech Stack

- Python
- TextBlob
- pandas
