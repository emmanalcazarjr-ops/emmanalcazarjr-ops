# Iris Flower Classifier

A simple machine learning project that classifies iris flowers into three species using a Random Forest classifier.

## Description

This project demonstrates a complete ML pipeline:
- Loading and exploring the Iris dataset
- Splitting data into training and testing sets
- Training a Random Forest classifier
- Evaluating model performance
- Making predictions on new data

## Installation

```bash
pip install -r requirements.txt
```

## Usage

```bash
python main.py
```

## Expected Output

The script will:
1. Display dataset information
2. Train the model
3. Show accuracy metrics and confusion matrix
4. Display sample predictions

## Tech Stack

- Python
- scikit-learn
- pandas
- numpy
